## 结论

**能用，但要按管线自己的取景规则重新排画布。** 8 帧 + 1 段 10 秒动态已经渲出来了；
两处必须知道的事：

1. **左半屏（dsh 窗口）的图是"截图"不是"实时画"** —— 换素材后必须重跑 `build.py pages`（实测 **387 秒**），否则窗口里还是旧图。
2. **立绘取景必须复刻原图的构图** —— 管线里有两处**写死的裁剪框**：`seg_page.avatars()` 的 `(250,40,690,480)` 和 `sprite_src()` 的 face/bust 比例框。画布排错了，头像就只剩额头（见 `framing-fix.png` 左）。

## 通过的

- **抠图干净**：浅灰背景去掉，粉色双马尾、红手套、白裙保留，边缘没有白边（`assets/cutout.png`）。
- **字符人像成立**：165 s 的 12 宫格里，蓝色字符清晰构出双马尾 chibi 轮廓（`smoke-8frames.png` 左下格）。
- **聊天窗口插图成立**：110 s「我一直在。」那条消息里的插图显示完整脸部（修取景后）。
- **8 个表情文件全部替换成功**：头像、mosaic、muted 等变体都跟着变。

## 不通过 / 需要调的

1. **必须重跑截图**。第一次冒烟时左窗还是旧角色——因为头像是 HTML 生成时烤进 PNG 的。这是最容易漏的一步。
2. **取景框要对齐原图**。第一版把半身像排在画布顶部，`(250,40,690,480)` 的头像框裁到了额头。改成「头宽 490 px、头顶贴 y=0、水平居中于 x=467」后对上（`framing-fix.png`）。参数在 `macos/prepare_character.py` 的 `target_w = 490`。
3. **这是半身像，不是全身立绘**。舞者 take 需要"脚线"定位，现在把胸像当站立像用，字符人像因此**偏矮胖**——能认出来，但不是原片那种全身姿态。要真做舞者，得补一张全身立绘（或改用 AI 生成全身）。
4. **抠图是启发式**（背景色距离 + 边界洪泛 + 连通块），这张图效果不错，但换图不一定成立；复杂背景需要重调 `BG_TOL`。

## 复现命令

```bash
# 1. 一张插画 → 三套画布
.venv/bin/python macos/prepare_character.py 源图.jpg 试片-粉发角色/assets

# 2. 替换素材（在工程副本里做，别动正式工程）
cp 试片-粉发角色/assets/dancer.png film/third_party_references/whale_maid_expanded_20260926/maid-left.webp
for f in film/third_party_references/whale_maid_expanded_20260926/expressions/*.webp; do \
  cp 试片-粉发角色/assets/sprite.png "$f"; done

# 3. 重建
.venv/bin/python tools/placeholder_h3.py --force   # 13 s
.venv/bin/python build.py pages                    # 387 s（不跑这步，左窗还是旧图）
.venv/bin/python build.py render                   # 66 s

# 4. 只看几帧（快）
cd film/pv_dsh_frontend_20260927 && ../../.venv/bin/python dsh_her.py stills 8.5 30 50 82 110 141 165 195
```
