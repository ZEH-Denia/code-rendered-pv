## 会让你的成片与原片不同的四件事（按影响排序）

### 1. 字体（必然发生，作者自己承认）

`docs/FONTS.md` 写明：换了字体「字宽不同，部分排版会轻微错位」。

- **Consolas 的字宽是 0.55 em**，而 macOS 上能选的等宽字体——JetBrains Mono / Menlo / Cascadia Mono——都是 **0.6 em**，**宽约 9%**。
- 这个片子是「固定像素容器 + 字符网格」的 TUI 版式，字宽差 9% 会让长行更靠近边框。我抽帧检查了 6 个时刻，**主版式没崩**，但逐字符位置必然与原片不同。
- 左边那半（Chromium 渲染的 dsh 窗口）更麻烦：它吃的是**系统 UI 字体**。原片是 Segoe UI + 微软雅黑，你是 SF Pro + PingFang，**行高和换行**都会变。
- 想尽量接近：把 OFL 字体用 `@font-face` 内嵌，并把 `seg.html` / `dsh_components.css` 里的字体族和 `line-height` 全部改成固定 px（现在用的是 CSS 变量 + 系统字体栈）。

四支字体，用环境变量覆盖：

```bash
export PV_F_MONO=/path/JetBrainsMono-Regular.ttf     # Windows: consola.ttf
export PV_F_MONO_B=/path/JetBrainsMono-Bold.ttf      #          consolab.ttf
export PV_F_CJK=/System/Library/Fonts/PingFang.ttc   #          msyh.ttc（系统字体，可直接用）
export PV_F_SYM=/System/Library/Fonts/Supplemental/STIXTwoMath.otf   # seguisym.ttf（∃ ⟨ ⟩ ⊢ ∀）
```

`build.py check` 的默认值是硬编码的 `C:/Windows/Fonts/...`，不设这四支就会报「missing font」。

### 2. 舞者替身（最大视觉差异，仓库有意为之）

原片的舞者画面（点云、样本格、特征图、热图、字符人像）是用第三方 MMD 模型 + 视频生成模型做的，**授权没谈下来，所以不在仓库里**。构建时 `tools/placeholder_h3.py` 用鲸鱼娘立绘生成同名同帧数的替身——「站着，随节拍轻轻摇摆」。

我实跑的成片里，所有舞者画面都是这个替身。要更接近原片：自己准备同格式帧（420×540 RGBA + 45 行×70 列字符网格），放进 `film/mmd_motion_eval_20260927/pv_cache/` 和 `continuity_full_v2/cache/h3_full_v1/`，替身工具看到已有文件会自动跳过（格式见 `placeholder_h3.py` 文档字符串）。

### 3. 作者自述的两处已知不一致

- 12.5–29 s 的检查点编号：成片用的截图早于最后一次改编号公式。
- 123.5 s 前后 3 帧：输入框发送按钮颜色不同，原因同上。

### 4. 后期亮度（未验证）

作者记录：114.75–114.83 s、159–161 s 最左两列有约 10 级亮度差，怀疑是 CPU/GPU 后期实现不同，**没做控制变量验证**。我们走 CPU 路径，这部分不复现。

> **无法做的验证**：原片在 B 站，我没有下载，所以给不出「逐像素差值 ≤ 8 级」这类结论。作者自己的验收口径是「差值超过 8 级的像素占比 ≤ 0.2%」，要复现这个需要拿到原片做比对。

## 音频：你其实已经有这首歌，但是加密的

在你机器上扫到：

```
~/Music/网易云音乐/Mili/world.execute (me) ; - Mili.ncm
~/Music/网易云音乐/Mili/world.execute (me) ; - Mili.lrc
```

- `.ncm` 是网易云的加密容器。走 [`ncmdump`](https://github.com/taurusxin/ncmdump)（Homebrew core 有 Apple Silicon bottle，v1.5.1）：`brew install ncmdump`。个人已经购买/下载的曲目转换回普通格式，属于个人使用范畴。
- 片子对齐的是 `sha256 = 79c4e5…`、211.913 s、320 kbps / 44.1 kHz 的那份。**时长一样就能用**，`check` 会提示 sha 不同但不阻断；若你那份片头多/少一段静音，用 ffmpeg 裁齐起唱点即可（`input/README.md` 有说明）。
- 正规购买路径：*Miracle Milk* **没有上 Bandcamp**，可在 [OTOTOY](https://ototoy.jp/_/default/p/100105) 买无损；Apple Music 有但带 DRM。
- 授权：[Mili 官方 Copyright Guidelines](http://projectmili.com/copyright-guidelines) 允许非商业个人二创；但本片**必须标注「包含 AI 生成内容」**（作者要求，也不能把纯代码渲染说成全部非 AI）。YouTube 整曲上传可能被 Content ID 自动认领，官方不受理申诉。

- Practical-RIFE（CUDA 依赖）、faster-whisper（CTranslate2 无 Metal）。

## 复刻步骤（约 15 分钟，一次装好）

```bash
git clone https://github.com/MisakaZentai/world-execute-me-dsh-pv.git
cd world-execute-me-dsh-pv

# 1. Python 环境（推荐 3.12）
uv venv --python 3.12 && uv pip install --python .venv/bin/python pillow numpy

# 2. Playwright
npm install && npx playwright install chromium

# 3. 字体（下载 JetBrains Mono，或换 Cascadia Mono）
export PV_F_MONO=$HOME/Library/Fonts/JetBrainsMono-Regular.ttf
export PV_F_MONO_B=$HOME/Library/Fonts/JetBrainsMono-Bold.ttf
export PV_F_CJK=/System/Library/Fonts/PingFang.ttc
export PV_F_SYM=/System/Library/Fonts/Supplemental/STIXTwoMath.otf

# 4. 歌曲
brew install ncmdump
ncmdump "~/Music/网易云音乐/Mili/world.execute (me) ; - Mili.ncm" -o input/
mv input/*.mp3 input/song.mp3

# 5. 出片
.venv/bin/python build.py all            # 实测 7 分 38 秒
.venv/bin/python build.py all --4k       # 另出 3840×2160
```

## 判断

- **能不能复刻**：能。这一版是**代码级复刻**——所有镜头、时间轴、网页、渲染都是确定性代码（每一帧是歌曲时间 t 的纯函数），不依赖任何模型权重或缺失素材。
- **复刻到什么程度**：结构 100% 一致（歌词时间轴我这边逐字节对上）；视觉差异集中在**字体**和**舞者替身**，而这两处正是作者自己开源重建时就承认的差异。
- **代价**：磁盘 1.6 GB、每次全片 8 分钟、4 个字体环境变量、一个歌曲来源问题（`.ncm` → mp3）。
