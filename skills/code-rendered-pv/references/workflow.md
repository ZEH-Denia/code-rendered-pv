# 七步工作流（详细版）

> 每一步都有闸门：不满足就别往下走。止损规则写在最后。

---

## 0. 定性

**要回答**：这东西到底是什么？交付物是什么形态？边界在哪？

- 是**复刻**一支现成片子（有源码/参考片）、**原创**一支（只有想法），还是**改造**一支（在现成工程上换素材/文案/配色）？三种活的最短路径完全不同。
- 交付物：分辨率、帧率、时长、编码、几份（正片/母版/4K/60fps）。
- 边界：能不能发布、能不能商用、署名怎么留、哪些素材不能进仓库。

**闸门**：交付物形态与验收口径能一句话说清。

## 1. 盘点

逐项**实查**，不要凭印象：

| 项 | 查什么 |
|---|---|
| 运行时 | Python 版本（系统自带的往往是 3.9，跑不动 3.12+ 的工程）、Node 版本、ffmpeg 是否带需要的编码器（`ffmpeg -encoders | grep -E "libx264|libx265|aac"`） |
| 依赖 | Playwright + 浏览器是否装、缓存多大 |
| 素材 | 歌曲/插画/字体是否齐；缺的能否替代（OFL 字体、替身素材） |
| 权限 | 是否需要 sudo、是否要联网下载、是否需要交互式登录 |
| 磁盘 | 完整构建的占用 ≈ 母版 + 截图 + 浏览器缓存；**余量要 > 需求的 2 倍** |
| 时间 | 用本机实测口径估算，不要拍脑袋 |

**闸门**：缺口 ≤3 项，且每一项都有替代方案。

## 2. 冒烟

用**替代品**跑通最小闭环：

- 缺歌 → 用 ffmpeg 生成同长度的静音 mp3
- 缺字体 → 用 OFL 字体 + 环境变量覆盖
- 缺素材 → 用代码生成替身

**闸门**：端到端能出东西，哪怕只有 4 秒、音画都不对。

> 冒烟会暴露 80% 的真问题：本技能来源的那单里，`ncmdump` 解出的是 FLAC 不是 MP3、`-shortest` 把片尾截掉 0.12 秒、字体路径硬编码——纸面评估一个都发现不了。

## 3. 补缺

把替代品换成真素材。换不了的**记账**，每处一条：

| 现象 | 证据 | 处置 |
|---|---|---|
| 成片比预期短 0.12 s | `ffprobe` 时长 211.78 vs 211.9 | 音轨短于视频，`-shortest` 截断；补尾到目标时长 |

**闸门**：每处替换都有文档、可回滚（保留原始文件）。

## 4. 全量

一次到底，别分步调试。

**闸门**：退出码 0 + 产物齐全（正片、母版、派生）。

## 5. 验收

按 `verification.md` 的清单跑。**闸门**：全部达标，或偏差已量化为「可接受」并写进交付说明。

## 6. 固化

把这次的修法写进脚本，而不是留在命令历史里：

- `setup-*.sh`：装环境（幂等，可重复跑）
- `run.sh`：一键出片，自动带环境变量
- `check_*.py`：可复跑的校验（A/V、对齐、素材规格）

**闸门**：换台机器照文档能从零复现。

## 7. 交付

命名、存放、标注（AI 生成内容、素材署名）、清单。

**闸门**：别人拿到能直接用，知道哪份是哪份。

---

## 止损规则（写死，别临场发挥）

- 缺口 > 3 项，或任何缺口没有替代方案 → 停下来问
- 磁盘余量 < 需求的 2 倍 → 先清盘或降规格
- 需要 sudo / 交互式登录 / 付费 API → 先报
- 验收有一项不达标且原因未明 → 交付时写清楚未达标，不要含糊过去
- 一次改动超过 30 分钟还没渲出可看的帧 → 停下来汇报，而不是继续猜

## 时间预算参考

| 场景 | 实测 |
|---|---|
| 冒烟（替代品 + 8 帧） | 15–25 min |
| 换素材整版重出 | 8 min（截图 400 s + 渲染 250 s） |
| 只重渲染（素材没变） | 60–250 s |
| 4K 重出（从母版） | 224 s |
| 逐帧验收（5085 帧全指标） | 2–3 min |
